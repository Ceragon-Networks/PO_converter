How to convert a PO — step by step

More detail on each step
1
Catalog is built in no setup

The Ceragon P/N catalog (3,583 entries) is embedded in the tool, so canonicalization works the moment you open it. If you need extra P/Ns beyond the built-in list — new releases, regional codes, etc. — click Add PNs… in the grey bar and pick an .xlsx with P/Ns in column A. Added P/Ns sit on top of the built-in catalog, are remembered in your browser, and can be removed with Remove added (the built-in list always stays).

2
Upload the customer PO (PDF)

Drag the PDF onto the upload box, or click it to browse. Leave Format on Auto-detect unless you already know it.

3
Click "Parse PDF"

The tool reads the PDF and tries to recognize the layout. Three things can happen — see step 4.

4
The tool recognizes the format — or asks you

Recognized: line items appear in the review table. Not recognized: a "Teach a new format" panel opens — pick a sample row, tag the part-number / quantity / price columns, name it and save (it's remembered for next time). Scanned PDF: no text to read — add lines by hand.

5
Review & fix

Check the header fields and line items. The Canonical Ceragon P/N column shows the catalog match for each line — green = exact / case-fixed / punctuation-fixed, amber = fuzzy match (verify), red = no match, purple = parser-resolved (some PDFs list the customer's vendor code alongside the real Ceragon P/N; the parser extracts both and puts the Ceragon P/N here automatically). Use the dropdown to pick another candidate, "— keep raw" to use the customer's exact spelling, or "✎ Custom" to open the catalog search: type any P/N to filter the 3,583-entry catalog, click a suggestion to apply it, or click ✓ Apply (or press Enter) to resolve what you typed: if it matches exactly one catalog P/N it is auto-accepted (canonical spelling, line clears review); if it matches several you get a warning on that line to pick the right one; if it matches none it is saved as a free-text custom P/N. The customer's original P/N stays in column U on the export, so the audit trail is preserved. The "need review" count flags only the rows where the match is uncertain. Edit quantities, prices or descriptions inline if needed; "+ Add line" for anything missed.

6
Export to Ceragon XLSX

Click Export to Ceragon XLSX. You get a file in the standard Ceragon BOM format: canonical P/N in column C, the customer's original P/N in column U, and a note in Remarks for any line that was corrected. Confirm the SUM matches the PO total before sending it on.

Everything runs in your browser — the PDF never leaves your machine. Saved catalog and learned formats persist between sessions.
